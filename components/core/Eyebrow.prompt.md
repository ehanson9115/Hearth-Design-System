**Eyebrow** — the tiny uppercase label above a title. Two sizes only: `page` (13px/500) above page and section titles, `card` (10.5px/500) for sub-sections *inside* a card — the one place CAPS is allowed in card copy.

```jsx
<Eyebrow>Your benefits</Eyebrow>
<h2>Food assistance</h2>

<Eyebrow level="card">Recent activity</Eyebrow>
```

Muted grey by default — it labels, it never shouts. Everything else stays sentence case.
