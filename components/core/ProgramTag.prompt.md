**ProgramTag** — a violet pill naming which program something belongs to (WIC, SNAP, FMNP). Identity, not status: it stays violet in every state, and status stays with `Badge`.

```jsx
<ProgramTag>WIC</ProgramTag>
<ProgramTag>SNAP</ProgramTag>
<ProgramTag dot={false}>FMNP</ProgramTag>
```

Use it on cards and rows that mix programs, so people can tell at a glance which benefit a line item belongs to.
